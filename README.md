# ☕ Coffee Supply Analysis | Tableau

An interactive **Coffee Supply Analytics Dashboard** built in **Tableau** to analyze coffee bean production, yield, geographic distribution, and production trends. The dashboard transforms coffee production data into an interactive visual analysis that helps users understand production patterns and identify high-performing regions.

## 🎯 Project Objective

The objective of this project is to transform coffee production and yield data into an interactive business intelligence dashboard.

The dashboard helps users analyze:

- Coffee bean production across countries and regions
- Coffee yield patterns
- Production trends over time
- Geographic differences in coffee production
- Relationships between production and yield
- Countries and regions contributing significantly to global coffee supply

---

## 📊 Dashboard Analysis

### 🌍 Geographic Production Analysis

The dashboard provides a geographic view of coffee production, allowing users to compare production levels across different countries and regions.

This helps identify major coffee-producing areas and understand the geographic distribution of global coffee supply.

---

### ☕ Coffee Bean Production

Production data is analyzed to understand how coffee output varies across countries and over time.

This allows users to identify:

- High-production countries
- Production trends
- Changes in coffee supply
- Regional differences in production

---

### 📈 Yield Analysis

Coffee yield is analyzed alongside production data to understand differences in agricultural productivity.

The analysis helps identify regions that produce larger quantities of coffee and regions that achieve stronger yields.

---

### 📅 Trend Analysis

Historical production and yield data can be explored to understand how coffee supply changes over time.

This helps identify periods of increasing or decreasing production and broader changes in coffee production patterns.

---

## 💡 Business Questions Answered

The dashboard allows users to investigate questions such as:

- Which countries produce the most coffee?
- Which regions contribute significantly to global coffee supply?
- How has coffee production changed over time?
- Which countries have higher coffee yields?
- How does coffee yield vary across regions?
- Which areas have strong production but relatively lower yields?
- What are the major geographic patterns in global coffee production?

## 🗂️ Dataset

This project uses two datasets related to global coffee production and yield:

| Dataset | Purpose |
|---|---|
| `coffee-bean-production.csv` | Coffee bean production data |
| `coffee-yields.csv` | Coffee yield data |

The datasets are stored in the `data/` directory of this repository.
